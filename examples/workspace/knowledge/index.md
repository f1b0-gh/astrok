# Astrok workspace

Explore a site built from Markdown, then try two interactive panels sharing
state between HTML controls and Solid components.

- [Read the guide](guide.md) — Try the controls and see how they work.
- [Use the documentation with AI agents](agents.md) — Find the original sources and cite them.

The guide and source downloads work without JavaScript. The interactive panels
use synthetic data from the example service; they are not a production application.
