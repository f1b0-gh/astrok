# Astrok logos

The mark combines a slanted stem and a lightning bolt.

| File | Use |
| --- | --- |
| [astrok-mark-dark.svg](astrok-mark-dark.svg) | White and yellow-green mark for dark backgrounds |
| [astrok-mark-ink.svg](astrok-mark-ink.svg) | Dark monochrome mark for light backgrounds |
| [astrok-mark-white.svg](astrok-mark-white.svg) | White monochrome mark for dark backgrounds or photos |
| [astrok-app-icon.svg](astrok-app-icon.svg) | App icon and favicon, with its own dark background |

Keep the proportions and slant. Leave clear space around the mark, and avoid
the colored version on light backgrounds where the lightning bolt loses contrast.
